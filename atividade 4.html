Observação

A regra 8 não é aplicada, pois nenhum elemento possui o ID lip5.

Hierarquia da especificidade CSS

1. ID (#) – maior prioridade.

2. Classes (.) e atributos ([]) – prioridade intermediária.

3. Elementos HTML (li, p, h1) – menor prioridade.
