Atividade 3 – Formas de aplicar uma modificação CSS em um HTML

Existem três maneiras principais de incluir CSS em documentos HTML:

1. CSS Inline

É aplicado diretamente em uma tag HTML por meio do atributo style. Permite modificar a aparência de um elemento específico.

2. CSS Interno (Internal CSS)

É escrito dentro da tag style, localizada geralmente na seção head do documento HTML. Permite aplicar estilos aos elementos da própria página.

3. CSS Externo (External CSS)

É escrito em um arquivo separado com a extensão .css e conectado ao documento HTML por meio da tag link. Facilita a organização e permite utilizar os mesmos estilos em várias páginas.
