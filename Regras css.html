Atividade 1 - Regras CSS

Conceito

Uma regra CSS é um conjunto de instruções utilizado para definir a aparência dos elementos de uma página HTML, permitindo alterar características como cores, fontes, tamanhos, espaçamentos e alinhamentos.

Partes de uma regra CSS

  • Seletor: indica qual elemento HTML será estilizado.
  • Propriedade: define o que será alterado.
  • Valor: determina como a propriedade será aplicada.

Exemplo:

p {
    color: blue;
}

Explicação do exemplo:

  • Seletor: p (seleciona todos os parágrafos).
  • Propriedade: color (define a cor do texto).
  • Valor: blue (define a cor azul).
